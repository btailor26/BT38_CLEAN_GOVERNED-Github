# BT38 Opportunity Qualification Pipeline

This directory is a completely separate prospecting workspace.

It does not import, call, deploy, or modify the BT38 application/runtime.

Pipeline:
DISCOVERED -> RESEARCHED -> QUALIFIED -> CONTACT_READY -> CONTACTED -> FOLLOW_UP -> CONVERSATION -> PROPOSAL -> WON / LOST / REJECTED

A prospect only reaches CONTACT_READY when all four gates pass:
1. Company fit
2. Current trigger / reason now
3. Ability to pay
4. Decision-maker + usable contact route

Hard rules:
- No duplicates.
- No anonymous companies.
- No generic Reddit/free-advice leads.
- No generic 3PL requests unless there is a separate operational/audit opportunity.
- No weak "might need help" prospects.
- Do not narrow Bhavin to inventory-only work. Review the wider ecommerce operating chain.
- Existing BT38 application/runtime remains untouched.

This area stores qualification rules and prospect records only.
